## 一、快速开始

### 1.1 本地打开游玩（桌面端，无需网络）

1. 解压本 ZIP 包到任意文件夹
2. 双击打开 **`问道长生.html`**
3. 游戏在浏览器中自动运行，无需登录、无需安装

**推荐浏览器**：Chrome / Edge / Firefox / Safari（最新 2 个版本）

### 1.2 iPhone 安装指南（添加到主屏幕，离线可玩）

> 本游戏为 PWA（渐进式 Web 应用），支持像 App 一样添加到 iPhone 主屏幕，全屏启动、离线游玩。

#### 步骤 1：部署到免费静态托管

将本 ZIP 包内的全部文件上传到以下任一免费静态托管平台，获得公开 HTTPS 链接。

**推荐：GitHub Pages（免费、稳定）**

1. 注册/登录 [GitHub](https://github.com)
2. 新建一个**公开仓库**（如 `wendaocangsheng`）
3. 上传本 ZIP 包内的**全部文件**（`问道长生.html`、`manifest.json`、`sw.js`、`icon-192.png`、`icon-512.png`）到仓库根目录
4. 进入仓库 **Settings → Pages**
5. Source 选择 **Deploy from a branch**，分支选 `main`，文件夹选 `/ (root)`
6. 保存后等待 1~2 分钟，访问 `https://你的用户名.github.io/仓库名/问道长生.html`

**替代方案**

| 平台 | 步骤概要 |
|------|---------|
| **Netlify** | 注册 → Add new site → Deploy manually → 拖拽上传全部文件 → 获得 `https://xxx.netlify.app` 链接 |
| **Vercel** | 注册 → Add New → Project → 导入 GitHub 仓库 → 自动部署 → 获得 `https://xxx.vercel.app` 链接 |
| **Cloudflare Pages** | 注册 → Create a project → 上传文件夹 → 自动部署 → 获得 `https://xxx.pages.dev` 链接 |

> **重要**：必须上传全部 5 个文件，PWA 才能正常工作。仅上传 `问道长生.html` 会导致离线功能和图标缺失。

#### 步骤 2：iPhone Safari 打开链接

1. 在 iPhone 上打开 **Safari** 浏览器
2. 输入步骤 1 获得的 HTTPS 链接，打开游戏页面
3. 等待页面加载完成（首次需要联网）
4. 点击 Safari 底部中间的 **分享按钮**（方框带向上箭头）
5. 在分享菜单中向下滑动，找到 **"添加到主屏幕"**
6. 点击后确认名称（默认"问道长生"），点击右上角 **"添加"**
7. 返回主屏幕，即可看到游戏图标

#### 步骤 3：离线游玩

- 首次打开主屏幕图标后，游戏会自动缓存到本地
- 之后**无需网络**即可点击图标直接启动游戏
- 游戏以全屏模式运行，无 Safari 地址栏和工具栏
- 如遇到更新后内容未刷新，可删除主屏幕图标后重新添加

## 二、存档机制说明

### 2.1 存档方式

本游戏使用浏览器 **localStorage** 进行本地存档：

- 游戏状态每 5 秒自动保存（v4 缩短间隔，提升离线精度）
- 关键操作（境界突破、历练完成）即时保存
- 关闭页面前自动保存

### 2.2 存档导出/导入（v4 新增）

**为什么需要导出存档？**

- iOS 系统清理网页数据时可能清除 localStorage
- 换设备/浏览器时需要迁移进度
- 作为备份防止意外丢失

**导出存档**：

1. 游戏中点击 **"设置" → "导出存档"**
2. 点击 **"生成并复制存档码"**
3. 将生成的长串文本码保存到备忘录、邮件等安全位置

**导入存档**：

1. 游戏中点击 **"设置" → "导入存档"**
2. 将之前保存的存档码粘贴到文本框
3. 点击 **"确认导入"**，当前进度将被覆盖为导入的存档

> **注意**：存档码包含你的全部游戏进度，请妥善保管，不要泄露给他人。

### 2.3 存档注意事项

| 场景 | 结果 |
|------|------|
 同一浏览器正常关闭后重开 | 存档自动恢复 |
| 换浏览器（如 Chrome → Firefox） | **存档丢失**，需通过导出/导入迁移 |
| 清除浏览器缓存/数据 | **存档丢失**，如有导出码可恢复 |
| iOS 系统清理网页存储 | **存档可能丢失**，建议定期导出备份 |
| 使用隐私/无痕模式 | **无法保存**，关闭窗口即丢失 |
| 同一浏览器的不同用户配置 | **存档隔离**，互不影响 |

## 三、玩法说明

### 3.1 核心循环

```
[打坐修炼] → [产出修为 + 灵石] → [消耗资源突破境界] → [解锁新内容]
        ↑_______________________________________________|
```

**三大操作**：

1. **手动打坐**：点击"打坐"按钮加速修炼，连续点击有连击加成
2. **境界突破**：修为达标后触发突破，成功则进入新境界
3. **历练探索**：消耗灵石派遣历练，倒计时结束后获得奖励

### 3.2 境界体系（十二大境界）

| 境界 | 名称 | 突破条件（修为） | 解锁内容 |
|------|------|-----------------|----------|
| 0 | 凡人 | — | 基础打坐、基础历练 |
| 1 | 练气期 | 100 | 解锁功法系统 |
| 2 | 筑基期 | 500 | 解锁装备系统、新历练地图 |
| 3 | 金丹期 | 2,000 | 解锁炼丹（被动增益）、灵石产出翻倍 |
| 4 | 元婴期 | 10,000 | 解锁心魔试炼、功法槽位 +1 |
| 5 | 化神期 | 50,000 | 解锁宗门、新历练地图 |
| 6 | 炼虚期 | 200,000 | 解锁双修、装备槽位 +1 |
| 7 | 合体期 | 1,000,000 | 解锁渡劫、功法品质提升 |
| 8 | 大乘期 | 5,000,000 | 解锁飞升倒计时、终极历练地图 |
| 9 | 渡劫期 | 20,000,000 | 渡劫功成（原通关点，现可继续突破） |
| 10 | 真仙 | 100,000,000 | 解锁仙品功法随机掉落，突破必得《大道归根篇》 |
| 11 | 金仙 | 500,000,000 | 解锁圣品功法随机掉落，突破必得《鸿蒙造化诀》 |

**突破规则**：
- 修为达到门槛即可尝试突破
- 金丹期起引入成功率（90% 起步，每境降低 5%，最低 60%）
- 突破失败不扣修为，但进入 30 秒虚弱（修炼速度减半）
- 消耗灵石可提高成功率（每次 +10%，最高 100%）
- 已达渡劫期的老存档加载后可继续向真仙、金仙突破，进度不受影响

### 3.2.1 功法品质体系

| 品质 | 修炼效率加成 | 获取途径 |
|------|-------------|---------|
| 凡品 | +10% ~ +20% | 历练 / 突破随机掉落 |
| 良品 | +20% ~ +35% | 历练 / 突破随机掉落 |
| 上品 | +35% ~ +55% | 历练 / 突破随机掉落 |
| 珍品 | +55% ~ +80% | 历练 / 突破随机掉落 |
| 绝品 | +80% ~ +120% | 历练 / 突破随机掉落（稀有） |
| 仙品 | +150% ~ +200% | 真仙（境界 10）起随机掉落；突破至真仙必得《大道归根篇》 |
| 圣品 | +250% ~ +300% | 金仙（境界 11）起随机掉落；突破至金仙必得《鸿蒙造化诀》 |

### 3.3 已实现功能清单

| 功能 | 说明 |
